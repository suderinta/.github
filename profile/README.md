# Suderinta – Verslo procesų automatizavimas ir programinė įranga

Oficiali **[Suderinta.lt](https://www.suderinta.lt)** atviro kodo bibliotekų ir integracijų repozitorija.

Kuriame individualią programinę įrangą, verslo valdymo sistemas (VVS/ERP), CRM sprendimus ir automatizuotas integracijas Lietuvos verslui.

---

### 🚀 Pagrindinės kompetencijos ir sprendimai

*   **[CRM ir Klientų valdymo sistemos](https://www.suderinta.lt/lp/crm-sistema)** – individualūs CRM sprendimai gamybos, transporto ir B2B paslaugų sektoriams.
*   **[Klientų savitarnos portalai](https://www.suderinta.lt/sprendimai/klientu-savitarnos-portalai)** – užsakymų, sąskaitų ir dokumentų pasirašymo sistemos.
*   **[Transporto ir logistikos valdymas (TMS)](https://www.suderinta.lt/sprendimai/logistikai-ir-transportui)** – maršrutų planavimas, krovinių sekimas ir telematikos integracijos.
*   **[Buhalterinių sistemų integracijos](https://www.suderinta.lt/blog/crm-integracija-su-rivile-ir-imas)** – Rivilė GAMA, Pragma, Finvalda, B1 ir VMI i.MAS / i.VAZ API integracijos.

---

### 📦 Atviro kodo įrankiai (Open Source Packages)

1.  **[lithuanian-company-validator](https://github.com/suderinta/lithuanian-company-validator)**  
    TypeScript/JavaScript biblioteka Lietuvos įmonių kodų (Modulus 11), PVM mokėtojo kodų ir banko IBAN sąskaitų validavimui.
2.  **[rivile-api-client](https://github.com/suderinta/rivile-api-client)**  
    Pilnai tipizuotas REST API klientas darbui su Rivilė GAMA ERP sistema (klientai, sąskaitos, sandėlio likučiai).
